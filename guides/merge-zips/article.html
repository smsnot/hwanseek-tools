Several ZIP files can contain different pieces of the same folder tree. Extracting each into its own named folder leaves you with repeated Takeout folders to sort through. With 7-Zip, you can extract their contents into one shared destination while keeping the internal folder paths.

Scope: ordinary, independent ZIP archives on Windows. This combines extracted folders; it does not build a new ZIP or repair an incomplete export.

The real problem

A Reddit user received 20 Google Takeout ZIPs containing folders with the same names but different contents. They also needed Google documents converted to Office formats, so a suggestion to use the Drive desktop app did not address the whole request. Later commenters reported that extracting all the ZIPs to the same location with 7-Zip kept the shared folder structure together. Those are commenter reports, separate from our practice test below.

Google explains that exports larger than the selected archive size produce multiple archives. Download every archive belonging to the export before deciding the extraction is complete.

Matching folder names are expected. A conflict is more specific: two files want the same complete relative path, such as Takeout/Drive/Projects/status.txt. The filename alone is not enough to decide whether files clash, and a shared path does not prove identical contents.

Free practice files

Download practice-01.zip, practice-02.zip, and practice-03.zip into one folder. They are three independent, tiny ZIPs made for this guide, with nine synthetic text/data files in total. They contain no real account data.

Keep the separate conflict-01.zip and conflict-02.zip for the optional collision exercise. Do not mix them into the normal nine-file exercise.

7-Zip settings for one folder tree

Use 7-Zip from its official site. The graphical settings below are documented by 7-Zip and checked against its official dialog source. Our completed extraction test used its command-line edition; we did not complete an end-to-end graphical extraction test.

  1. Keep the original ZIPs. Make a separate, empty output folder named merged. Ensure the destination drive has room for the unpacked contents as well as any archives you are keeping there.
  2. Open 7-Zip File Manager and browse to the folder containing the three practice ZIPs. Select only those archives. Choose File → 7-Zip → Extract files..., or use the Extract toolbar button.
  3. Set Extract to to the same merged folder for every archive. If the dialog displays a separate archive-name subfolder field, disable its checkbox and enter the complete destination in the main field. Do not leave an extra * or per-archive name appended to the destination.
  4. Set Path mode → Full pathnames to preserve the archived folders. Set Overwrite mode → Ask before overwrite. Check the settings explicitly because a previous choice may have been remembered.
  5. Start extraction. If a same-path file prompt appears, stop and review it; do not approve overwriting every file just to finish. When extraction completes, read any errors and check the output before using it.

The path and overwrite options are described in the installed 7-Zip Help under File Manager → Plugins → 7-Zip → Extract Dialog. The current official dialog implementation also confirms that a separate subfolder can be appended to the main destination and that settings may be retained. A PeaZip guide offers an alternative interface for multiple-archive extraction with path and collision controls; we did not test PeaZip here.

What we actually checked

On September 9, 2026, we used 7-Zip 24.08 x64 on Windows 10 Home 22H2. The official download page listed 26.03 that day; that newer version was not our test environment. The test used synthetic ZIPs and the installed command-line extractor, with each archive pointed at the same empty destination.

  • Separate extraction produced three separate Takeout trees. Shared-destination extraction produced one tree with all nine expected files.
  • Every expected relative path and file SHA-256 hash matched. Spaces, a Korean filename, nested folders, and identical basenames in different folders were preserved.
  • All five original practice and conflict ZIPs remained byte-for-byte unchanged.
  • Omitting the third ZIP still let the other two extract successfully, but only six files were present. A successful extraction message does not establish that you downloaded the whole set.

See the test record, expected file hashes, and expected folder tree. We did not measure a time-saving percentage or test a large personal Takeout export.

When the same path has different contents

The two conflict ZIPs both contain Takeout/Drive/Projects/status.txt, but one says version A and the other says version B. Our separate command-line checks demonstrated why no automatic choice is universally correct:

ChoiceObserved result
Answer No / skip existingVersion A stayed; version B was not extracted. The command still reported success.
OverwriteVersion B replaced A in the output folder. The original ZIPs still held both versions.
Auto renameBoth versions were kept as status.txt and status_1.txt. This preserves the bytes but changes a name.

For an unexpected collision, preserve the archives and extract the conflicting archive to a different review folder. Compare the files before deciding which version belongs where. Renaming can break references or filename-based relationships, so keeping two files is not the same as repairing an application backup.

What this does not solve

  • Actual split archives: names such as backup.zip.001 and backup.zip.002 can be volumes of one archive. Keep all volumes together and follow the format's first-volume extraction procedure. Do not treat them as separate, complete ZIPs. The PeaZip documentation explains this distinction.
  • Missing or damaged downloads: test the archives, check extraction errors, and compare the downloaded set with the export's download list. Extraction cannot recreate an absent file.
  • Space and filesystem limits: packed size is not unpacked size. A full drive, very long paths, filename restrictions, permissions, or an interrupted extraction can leave an incomplete output.
  • Google Photos metadata: combining folders does not apply JSON metadata to photos, restore albums, or prove that a cloud account was exported completely.

Use the small practice set first. For the normal exercise, the result should be one Takeout folder containing nine files, with the original ZIPs still available.
